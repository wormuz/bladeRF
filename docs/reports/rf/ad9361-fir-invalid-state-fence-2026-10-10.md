# AD9361 FIR partial-write validity fence — 2026-10-10

`ad9361_load_fir_filter_coef()` writes coefficient RAM sequentially. On an SPI error after coefficient writes begin, cleanup restores the FIR clock/enable fields and ENSM state but cannot restore the prior coefficient image. The public RX and TX FIR setters correctly leave `phy->fir_config_valid` false after the failed update. Before this change, RX transition begin did not inspect that flag, and the TX RFIC certificate considered only RFPLL, ENSM, BBPLL, and calibration status. A later transition could therefore certify samples or TX admission while the filter state was known invalid.

libbladeRF now rejects RX transition begin while the host AD9361 PHY is unavailable, its overall FIR clock/bandwidth validation is false, or the required coefficient lane masks are incomplete; this rejection emits `BLADERF_RF_EVT_ERROR` with the returned status. TX RFIC observation distinguishes invalid FIR configuration from invalid RFPLL/ENSM/BBPLL status. An invalid FIR state emits `TX_CONFIGURATION_INVALID` and aborts TX admission without setting the hard recovery block, allowing a full FIR rewrite followed by the normal TX retune/revalidation flow. Actual PLL/ENSM/BBPLL invalidity still takes the existing hard fail-closed path. A new policy predicate and source regression protect this distinction so FIR-only invalidity remains recoverable while a measured RFIC-state fault remains hard-blocking. no-OS tracks coefficient validity separately for RX1, RX2, TX1, and TX2; a partial failure clears the whole affected direction mask because its gain/decimation controls are shared, and recovery of the opposite direction cannot restore the aggregate flag. On dual-channel devices both lanes in both directions must be reprogrammed successfully before the flag becomes valid. The pure transition-policy source regression covers missing PHY, incomplete RX/TX lane masks, failed overall validation, single-channel masks, and recoverable FIR-invalid TX observation.
