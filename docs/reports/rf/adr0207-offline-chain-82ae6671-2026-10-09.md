## Result

Built a matched offline candidate from bladeRF `82ae6671`, no-OS submodule
`b7e1fe46e`, and python_bladerf `33cc48f`. It contains A4 hosted/sweep FPGA
images, their matching NIOS ELFs and RAM initialization, libbladeRF
`2.6.1-git-82ae6671`, a no-RPATH CPython 3.14 wheel, the compatible FX3 image,

This is not a stable or hardware-qualified release. The exact image pair was
not loaded: the xA4 is still being preserved after its NIOS no-response
incident. The no-response root cause and archived LTE no-PSS RF-content case
remain open P0 gates.

## Change in this source revision

NIOS AD9361 SPI read failures were silently converted to zero-valued reads in
the direct packet path and several PLL/fastlock routines. The new checked-read
path propagates transport errors through NIOS responses and the host API;
fastlock and PLL routines no longer treat a failed read as a valid status.
Regression tests inject SPI read failures and assert the failure reaches the
host with data cleared rather than reporting success.
