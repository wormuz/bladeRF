# Збірка гейтверу з вердиктом

Шість ручних кроків в один. Саме через їх ручність двічі за сесію читалось
`.sta.summary` замість того, щоб одразу дивитись самі шляхи — а зведення
показує лише домени, не місця.

## Порядок

### 1. Радіо й попередні прогони

    pgrep -f quartus >/dev/null && echo busy || echo free

⛔ Якщо зайнято — не запускати другу збірку: вони ділять
`hdl/quartus/work/`, і друга зіпсує першу.

### 1a. Статична перевірка — ПЕРЕД збіркою, не після

    ./qcheck

Секунда роботи проти чотирнадцяти хвилин. Тримає по одному правилу на
кожен клас дефекту, який у цьому репозиторії вже коштував збірки:
фатальне повідомлення в SDC, шаблон що змішує інстанси, false path який
забирає межу перекосу, `-from` без `-to`, regexp по ієрархії зі
зворотними слешами, блок що прив'язав нуль інстансів і мовчить, сирі
`rx_`/`tx_` у міждоменному слові, АБО двох доменів, `*/` усередині
коментаря C.

⛔ Не запускати збірку, поки `qcheck` не чистий. Кожне з цих правил
з'явилось після втраченого дня.

    ./qcheck --list    що саме перевіряється і чого це коштувало

### 2. Збірка

    cd ~/projects/bladerf/hdl/quartus
    nohup ~/soft/q25 ./build_bladerf.sh -b bladeRF-micro -r hosted -s A4 -l full \
        > /var/tmp/q25_$(date +%H%M).log 2>&1 &

Триває близько чотирнадцяти хвилин. Не чекати `sleep`-циклом.

### 3. Ворота

    ./qgate /var/tmp/<лог> --warn

Перевіряють помилки, критичні попередження, `Ignored`, порожні колекції,
`No path is found`, недійсні винятки, ненульові неконстрейнені шляхи.

⛔ Зелені ворота ≠ закритий таймінг. Вони кажуть лише, що обмеження
прив'язались.

### 4. Вердикт таймінгу

    D=$(ls -dt hostedxA4-* | head -1)
    grep -cE '^Slack\s*:\s*-' $D/hostedxA4.sta.summary

Нуль — таймінг закритий. Інакше далі.

### 5. Самі шляхи, не домени

Зведення називає лише домен, а домен ≠ місце. Двічі через це шукалось не там:
`FROMCLK ...|pll_sclk|divclk` читалось як «зривається інтерфейс LVDS», хоча
винна логіка була наша.

    cd hdl/quartus/work/bladerf-micro-A4-hosted
    CAP_RUN_OK=180 ~/soft/q25 quartus_sta -t /tmp/paths.tcl 2>&1 | grep "^S "

де `/tmp/paths.tcl` відкриває ревізію `hosted` проєкту `bladerf`, будує
netlist на потрібному куті (`-model slow -temperature 85 -voltage 1100`,
БЕЗ `-post_fit` — вони несумісні), і друкує для кожного шляху slack,
`-from` і `-to` через `get_path_info`.

### 6. Приймання

Перед тим як назвати результат закритим:

    Agent sdc-binding-verifier    чи кожне обмеження прив'язалось
    Agent cdc-inventory-guard     чи кожен перетин класифікований

## Заборони

⛔ Свип сідів (`run_dse.sh`) — лише коли жоден домен не має від'ємного
запасу. Свип по недійсній збірці міряє розподіл дефекту.

⛔ `quartus_dse` клонує `hdl/quartus/work/`, тож перед ним потрібна чиста
збірка поточного коду. Інакше свип міряє стан, який уже виправлено, і це
виглядає як катастрофічна регресія — так і сталося.

⛔ Не прошивати образ із відомим порушенням таймінгу: вимір із нього нічого
не доводить.
